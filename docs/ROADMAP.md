# 다음에 할 일

우선순위 순으로 적는다. 앞의 둘은 지금 결과에서 바로 이어지는 작업이다.

## 1. 파지 하강 규칙을 뺀 조건으로 30판 재측정

절제 실험에서 이 규칙이 해롭다는 것이 드러났다(9/10 대 3/9). 지금 공개한 43.3 % 는 불리한
설정의 값이므로, **같은 30세트 배치로 다시 재야 한다.** 반나절이면 끝난다.

## 2. 공간 추종 개선 — 데이터 추가 수집

```
현재   그릇이 10 cm 이동할 때 파지점은 3.5 cm 이동 (x 0.36 / y 0.35)
```

테두리 두께가 4~5 mm 인데 좌우 오차가 2 cm 급이라, 헛잡음 7판이 여기서 나온다.
205판을 늘리되 **그릇 위치를 지금보다 넓게 흩어** 모으는 것이 핵심이다. FR3 쪽은 101 → 200판
에서 파지 구간 오차가 21 % 줄었다.

학습 스텝을 늘리는 방향은 이미 막혔다 — 12,000 스텝은 추종이 0.1 로 떨어졌다.

## 3. 밀림을 줄이는 파지 제어

잡은 뒤 완전 폐쇄를 유지하면 경사면에서 테두리가 밀려 나간다. 문 폭에서 버티게 하면
조이는 힘이 안 걸려 못 잡는다. 둘 사이가 필요하다.

```
후보   힘을 낮춘 상태에서 문 폭 + 1 mm 위치를 유지
       그리퍼 상태 2(물체에 걸림) 를 피드백으로 쓰는 폐루프
       손가락 패드 교체 — 마찰을 올리면 설정으로 풀 필요가 없다
```

## 5. 회전이 필요한 태스크

이 태스크에서는 회전이 한 스텝에 1.11° 밖에 변하지 않아 학습 신호가 없다
([ROTATION.md](ROTATION.md)). 회전 채널을 제대로 평가하려면 기울여 붓기처럼 **회전이 결과를
바꾸는 태스크**로 옮겨야 한다.

## 6. FR3 데이터와의 이종 전이

같은 태스크를 7축 Franka FR3 에서 수집한 데이터가 있다. 액션 규약이 동일함을 확인했으므로
(`action[t] = state[t+1][:7]`, 오차 0) 양쪽 데이터를 섞거나 한쪽에서 다른 쪽으로 옮기는
실험이 가능하다. 두 로봇의 손끝 자세는 같은 접근축을 중심으로 약 77° 차이가 있어, 그 보정이
전제다.

## 7. denoise 스텝

현재 16(약 400 ms)이다. FR3 쪽은 4가 더 빠르면서 정확했다고 보고한다. 측정이 끝난 지금은
바꿔서 비교해 볼 수 있다.
