# 구성

## 1. 장비

```
로봇        FAIRINO FR5 (6축)
그리퍼      DH AG-95, Modbus RTU
제어 PC     Jetson AGX Thor (aarch64) — FAIRINO Python SDK 2.2.2, ROS 없음
카메라      Intel RealSense D405 ×2 — 3인칭(에이전트 뷰), 손목
학습·추론   RTX PRO 6000 Blackwell 97 GB ×2 서버
리더암      Feetech STS3215 ×7, 수동 6자유도 (별도 저장소)
```

제어 PC 에서 작은 웹 제어판이 로봇 연결을 독점한다. 수집기·모니터·롤아웃은 모두 이
제어판에 HTTP/UDP 로 붙으므로 동시에 띄울 수 있다.

```
리더암 ──UDP 50Hz──▶ 제어판(안전 필터) ──ServoJ 125Hz──▶ FR5
정책 서버 ──HTTP──▶ 롤아웃 ──같은 UDP 경로──▶ 제어판
```

롤아웃은 리더암 자리에 정책을 끼워 넣는 구조다. **사람이 조작할 때와 똑같은 안전 필터를
통과한다** — 속도·가속 상한, 관절 소프트 한계, 작업대 바닥(45 mm), 값 튐 차단.

## 2. 작업 프레임

로봇 베이스를 z축 기준 **−77.2°** 회전한 것이 작업 프레임이다. 데이터의 모든 좌표가 이
기준이다.

```
+x   로봇에서 멀어지는 방향        +y   +x 를 볼 때 왼쪽        +z   위
```

```
x_w =  x_b·cos(77.2°) + y_b·sin(77.2°)
y_w = −x_b·sin(77.2°) + y_b·cos(77.2°)
z_w =  z_b
```

제어기 자세각은 고정축 XYZ 규약이다 (R = Rz·Ry·Rx).

### 기구학

UR 계열 표준 DH 로 FR5 를 기술한다. 실측 세 자세와 **0.4 mm 이내**로 맞다.

```
d1 = 152,  a2 = -425,  a3 = -395,  d4 = 102,  d5 = 102,  d6 = 100  [mm]
alpha = [+90, 0, 0, +90, -90, 0]  [deg]
공구     플랜지에서 공구축 +z 167.6 mm   (관절각·제어기 TCP 역산 167.87, 캘리퍼 실측 전)
```

역기구학은 수치 해(자코비안 감쇠최소자승)를 쓴다. 롤아웃 크기의 목표 300회에서 실패 0,
최대 오차 0.019 mm, 0.8 ms/회.

## 3. 그리퍼

```
위치 0 ~ 1000   →  반폭 0 ~ 0.04 m          grip_width[m] = pos/1000 × 0.04
힘   20 ~ 100 % (레지스터 0x0101)
상태 1 도달 / 2 물체에 걸림 / 3 놓침
```

평가에는 힘 70 % 를 썼다. 힘을 올리면 테두리를 밀어내는 성분도 같이 커져 역효과다
([ROLLOUT.md](ROLLOUT.md) 참조).

## 4. 관측

두 카메라를 848×480 으로 받아 **256×256 으로 줄이기만 한다.** 크롭도 반전도 없다.
손목 카메라는 물리적으로 180° 돌아 장착돼 있고, 학습과 추론이 같은 화면을 보므로 그대로 쓴다.

![관측](../fig/fig13_views.png)

노출과 화이트밸런스는 고정한다.

```
third  exposure 25600,  white balance 3600
wrist  exposure 17300,  white balance 3800
```

밝기는 **에피소드 전체 평균**으로 관리한다. 수집 데이터 기준은 third 116.6 / wrist 90.5 이고,
평가 당일 측정값은 third 119~121 / wrist 90~100 으로 ±10 안이었다.
카메라를 재시작할 때마다 노출을 다시 넣어야 한다.
