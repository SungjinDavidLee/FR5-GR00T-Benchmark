# 데이터셋

## 1. 수집

수동 리더암으로 조작해 205판을 모았다. 리더암에는 토크가 없어 중력 보상이 되지 않으므로,
조작 중에는 손을 놓지 않는다.

```
판 수 / 프레임     205 / 10,482        판당 평균 51 프레임 (31 ~ 125)
기록 주기          명목 10 Hz, 실측 약 3.4 Hz
손상·누락          0
```

판마다 물체를 다시 배치했고, 흐름은 이렇다.

```
접근 → 하강 → 정렬 → 파지 → 들기 → 이송 → 놓기 → (기록 밖에서) 복귀·재배치
```

시작 그리퍼는 205판 모두 완전 열림(pos 1000 = 0.04 m)이다.

## 3. 학습용 규약

FR3 쪽 `task6_franka_v5` 와 같은 형식이다. 대조해서 **오차 0 으로 동일**함을 확인했다.

```
observation.state  8차원 = x, y, z, aa1, aa2, aa3, gripper, −gripper
action             7차원 = 다음 프레임의 절대 state 앞 7개 (마지막 프레임은 자기 자신)
영상               observation.images.image / observation.images.wrist_image
```

델타가 아니라 **절대값**을 넣고 `use_relative_actions=true` 로 학습한다. GR00T 가 내부에서
상대화하므로, 델타를 미리 만들어 넣으면 이중 처리가 되어 청크 경계가 깨진다.

### 축각 정규화

축각은 같은 회전을 두 가지로 적을 수 있고, 크기가 π 근처면 표현이 갈릴 수 있다.
이 태스크의 자세가 정확히 그 자리에 있어(크기 중앙 3.14, 47 %의 프레임이 π 초과)
판 첫 프레임 기준으로 가까운 쪽을 고르는 정규화를 둔다.

```
ref_axis_angle = [-2.4425330290871115, 1.968073832566227, 0.0019828086840627443]
```

205판 전체를 검사한 결과 **표현이 갈린 프레임은 0개**다 ([ROTATION.md](ROTATION.md)).

### 파지 좌표는 물체 중심이 아니다

기록된 파지 좌표는 **그릇 중심이 아니라 접시 쪽 테두리**다. 13판 실측으로 잰 차이:

```
파지 지점 − 그릇 중심 =  x −11 ± 23 mm,   y −70 ± 15 mm
```

그릇 반지름이 60 mm 이므로 y 치우침이 반지름과 같은 크기다. **데이터의 파지 좌표를 물체
위치로 그대로 쓰면 7 cm 어긋난다.** 평가 배치를 만들 때 이 보정을 적용했다
([RESULTS.ko.md](../RESULTS.ko.md) 4절).
